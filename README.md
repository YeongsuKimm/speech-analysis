Use:
1. First, go to vods folder and put in the links to the vods of all the streamers
2. Use the auto_data.py file to automate collecting clips and storing it in the data folder
3. Collect metadata using the metadata.py file
3. Organize the collected data by running process_audio_files("data") and find_text_audio_pairs("data")
4. Extract the data by running the file extract_data.py
5. Train the model 
6. Use the evaluator to test results
